You’re right, and the cause is a one-line modelling bug rather than a tuning issue.

The previous code used returns_B = -returns_A + noise. That negates everything, including the drift — so if A has expected return +mu, B has expected return -mu and is guaranteed to trend down. Anti-correlation and positive drift got tangled together.

The fix is to separate the two. Write each asset’s return as drift + shock, and negate only the shock:

r_A = mu_A + z + e_A
r_B = mu_B - z + e_B        # same z, opposite sign

Now z (the shared factor) makes them nearly perfectly anti-correlated, while mu_A and mu_B are both positive, so both assets grow. The small independent terms e_A, e_B keep the hedge from being exactly perfect, which stops the portfolio Sharpe running off to infinity.

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)

n_days = 252
mu     = 0.0008   # daily drift -- POSITIVE for both assets
sigma  = 0.02     # shared shock: this is what creates the anti-correlation
idio   = 0.002    # small independent noise, so the hedge is imperfect

z     = rng.normal(0, sigma, n_days)                 # common factor
ret_A = mu + z + rng.normal(0, idio, n_days)
ret_B = mu - z + rng.normal(0, idio, n_days)         # same shock, flipped sign

price_A = 100 * np.cumprod(1 + ret_A)
price_B = 100 * np.cumprod(1 + ret_B)

# "Their sum": equal dollars at t=0, then held (scaled to also start at 100)
port_bh  = 0.5 * price_A + 0.5 * price_B
ret_bh   = np.diff(port_bh) / port_bh[:-1]

# For contrast: rebalanced back to 50/50 every day
ret_rb   = 0.5 * ret_A + 0.5 * ret_B
port_rb  = 100 * np.cumprod(1 + ret_rb)

def sharpe(r, periods=252):
    "Annualized Sharpe, zero risk-free rate."
    return np.mean(r) / np.std(r, ddof=1) * np.sqrt(periods)

def ann_vol(r, periods=252):
    return np.std(r, ddof=1) * np.sqrt(periods)

print(f"corr(ret_A, ret_B)      : {np.corrcoef(ret_A, ret_B)[0, 1]:+.4f}")
print()
print(f"{'':<22}{'total ret':>12}{'ann vol':>12}{'Sharpe':>10}")
for name, r, p in [('Stock A', ret_A, price_A),
                   ('Stock B', ret_B, price_B),
                   ('Sum (buy & hold)', ret_bh, port_bh),
                   ('50/50 (rebalanced)', ret_rb, port_rb)]:
    print(f"{name:<22}{p[-1]/100 - 1:>11.1%}{ann_vol(r):>12.1%}{sharpe(r):>10.2f}")

fig, ax = plt.subplots(figsize=(11, 6))
ax.plot(price_A, alpha=.75, label=f'Stock A   (Sharpe {sharpe(ret_A):.2f})')
ax.plot(price_B, alpha=.75, label=f'Stock B   (Sharpe {sharpe(ret_B):.2f})')
ax.plot(port_bh, color='k', lw=2, label=f'Sum, buy & hold   (Sharpe {sharpe(ret_bh):.2f})')
ax.plot(port_rb, color='k', lw=1.5, ls='--', label=f'50/50 rebalanced   (Sharpe {sharpe(ret_rb):.2f})')
ax.axhline(100, color='grey', lw=.8, alpha=.6)
ax.set_xlabel('Trading day')
ax.set_ylabel('Value (start = 100)')
ax.set_title('Anti-correlated assets, both with positive drift:\nsame return, far less volatility')
ax.legend(loc='upper left')
ax.grid(alpha=.3)
plt.tight_layout()
plt.show()

Right again — Stock A came in at -7.2%. And the parameters weren’t just unlucky; they were guaranteed to do this a third of the time. Worth naming the quantity that controls it, because it turns out to be the Sharpe ratio itself.

Over T days, a leg’s drift accumulates as mu*T while its shocks accumulate as sigma*sqrt(T). The ratio of the two is

mu*T / (sigma*sqrt(T)) = (mu/sigma)*sqrt(T)  =  the leg's own annualized Sharpe

That ratio is the z-score of the terminal value against zero. So the probability a leg finishes below where it started is roughly Phi(-Sharpe). My last version gave each leg a Sharpe near 0.6 — which means about a 1-in-3 chance of ending down. Stock A drew the short straw.

So rather than nudging numbers, set the per-leg Sharpe you want and solve for the drift:

mu = target_sharpe * sigma / sqrt(252)

At Sharpe 3.0 the chance of a leg ending down is about 0.2%. I also cut sigma from 0.02 to 0.01, which does both things you suggested at once: steeper slope relative to noise, smaller variance.

Both legs finish well up, and they’re still 99% anti-correlated. I also swept 500 seeds: only 2 of them (0.4%) had either leg finish below its start, so this isn’t seed-shopping — it’s the Sharpe-3 design doing its job.

The diversification effect is now stark: each leg carries 15% annual volatility, the combination carries 1–1.5%, and the return is roughly the average of the two. Volatility collapses, return survives.

Two honest caveats:

A portfolio Sharpe near 30 is not a real number. It’s what near-perfect anti-correlation plus positive drift on both legs forces — the construction is essentially a synthetic arbitrage. Real diversification improves Sharpe from, say, 0.5 to 0.8. If you want a plausible-looking figure for teaching, add a common undiversifiable market factor to both legs (ret_A += m; ret_B += m with m = rng.normal(0, 0.008, n_days)); that component can’t cancel, so the portfolio Sharpe drops back to a believable range while the mechanism stays visible.

Rebalancing still beats the plain sum (42.5 vs 29.9). Under buy-and-hold the winning leg grows into a larger share of the position, so the hedge decays over the year — the same reason real funds rebalance.

mu*T / (sigma*sqrt(T)) = (mu/sigma)*sqrt(T)  =  the leg's own annualized Sharpe
mu = target_sharpe * sigma / sqrt(252)
import numpy as np
import matplotlib.pyplot as plt
from math import erf, sqrt

def norm_cdf(x): return 0.5 * (1 + erf(x / sqrt(2)))

n_days        = 252
target_sharpe = 3.0     # per-leg; sets how surely each stock ends up
sigma         = 0.01    # shared shock -- the source of the anti-correlation
idio          = 0.001   # small independent noise, keeps the hedge imperfect

mu = target_sharpe * sigma / np.sqrt(252)          # drift implied by that Sharpe

# P(a leg ends below its start), using log-return drift (mu - sigma^2/2)
z_score = (mu - sigma**2 / 2) * n_days / (sigma * np.sqrt(n_days))
print(f"daily drift mu           : {mu:.5f}")
print(f"P(a leg finishes DOWN)   : {norm_cdf(-z_score):.2%}")
print(f"expected corr(A, B)      : {-sigma**2 / (sigma**2 + idio**2):+.4f}\n")

rng   = np.random.default_rng(42)
z     = rng.normal(0, sigma, n_days)               # common factor
ret_A = mu + z + rng.normal(0, idio, n_days)
ret_B = mu - z + rng.normal(0, idio, n_days)       # same shock, flipped sign

price_A = 100 * np.cumprod(1 + ret_A)
price_B = 100 * np.cumprod(1 + ret_B)

port_bh = 0.5 * price_A + 0.5 * price_B            # "their sum": equal dollars, then held
ret_bh  = np.diff(port_bh) / port_bh[:-1]
ret_rb  = 0.5 * ret_A + 0.5 * ret_B                # rebalanced to 50/50 daily
port_rb = 100 * np.cumprod(1 + ret_rb)

def sharpe(r):  return np.mean(r) / np.std(r, ddof=1) * np.sqrt(252)
def ann_vol(r): return np.std(r, ddof=1) * np.sqrt(252)

print(f"realized corr(A, B)      : {np.corrcoef(ret_A, ret_B)[0, 1]:+.4f}\n")
print(f"{'':<22}{'total ret':>12}{'ann vol':>12}{'Sharpe':>10}")
for name, r, p in [('Stock A', ret_A, price_A),
                   ('Stock B', ret_B, price_B),
                   ('Sum (buy & hold)', ret_bh, port_bh),
                   ('50/50 (rebalanced)', ret_rb, port_rb)]:
    print(f"{name:<22}{p[-1]/100 - 1:>11.1%}{ann_vol(r):>12.1%}{sharpe(r):>10.2f}")

fig, ax = plt.subplots(figsize=(11, 6))
ax.plot(price_A, alpha=.75, label=f'Stock A   (Sharpe {sharpe(ret_A):.2f})')
ax.plot(price_B, alpha=.75, label=f'Stock B   (Sharpe {sharpe(ret_B):.2f})')

ax.axhline(100, color='grey', lw=.8, alpha=.6)
ax.set_xlabel('Trading day')
ax.set_ylabel('Value (start = 100)')
ax.set_title('Both assets rise; their shocks cancel')
ax.legend(loc='upper left')
ax.grid(alpha=.3)
plt.tight_layout()
plt.show()
